# Customer Review Sentiment Analysis using NLP

## Project Overview
This project analyzes customer/movie reviews and classifies them into Positive or Negative sentiment using Natural Language Processing (NLP) and Machine Learning.

## Technologies Used
- Python
- Google Colab
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Logistic Regression
- Matplotlib
- Seaborn

## Dataset
The project uses the NLTK Movie Reviews dataset containing 2000 labeled reviews:
- 1000 Positive reviews
- 1000 Negative reviews

## Methodology
1. Dataset Collection
2. Text Preprocessing
3. Train-Test Split
4. TF-IDF Feature Extraction
5. Logistic Regression Model
6. Model Evaluation
7. Sentiment Prediction
8. Data Visualization

## Results
The trained model predicts whether a review expresses Positive or Negative sentiment.

## Sample Prediction
Input:
"I really loved this movie, it was amazing."

Output:
Positive
